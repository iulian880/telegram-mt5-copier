## TGMT5 0.4.0

A safety and interface release. Twelve backend bugs found in a code review are fixed, each with a regression test (`tests/test_regressions_v040.py`), and the interface got a visual upgrade.

### Download

| File | Use it when |
|---|---|
| `TGMT5-Setup-0.4.0.exe` | Normal install. Run it over 0.3.x: settings, history and passwords are kept. |
| `TGMT5-Portable-0.4.0.exe` | One self-contained file to copy and run, no install. Keeps its data in `TGMT5-data` next to the `.exe`. |

Both are built and smoke-tested on GitHub Actions (Windows, `--sandbox` start-up check). They are signed with a self-signed test certificate, so SmartScreen warns: **More info → Run anyway**.

### Trading safety fixes

- **Chat was read as commands.** "Gold is getting close to TP1" closed every open position; "Keep your SL, be patient" moved stops to breakeven; "Take only 1% risk" closed 1%; "Don't close yet" closed everything. Follow-up commands now need explicit wording, negations are ignored, and conditional closes ("close at 2665 if…") go to manual review.
- **Pending orders.** Most servers acknowledge a pending order with DONE (10009). It was stored as an open position, then marked CLOSED on the next tick while the real order stayed at the broker, unmanaged. Now it stays PENDING.
- **Repeated partial closes.** A broker error on one signal rolled back the whole management tick, so partial closes already sent for other signals were sent again. Each signal is now committed on its own.
- **Signals stuck in SUBMITTING.** An error right after a successful order left the trade unmanaged. The order is now recorded as open regardless.
- **Duplicate orders after a timeout.** After a timed-out send, the broker is checked again after a short pause before any retry.
- **Broker server time.** MT5 reports times in server time (UTC+2/+3 at IC Markets). It was read as UTC, so recent closes were missed (losses were not counted by the consecutive-loss breaker) and the stale-quote check was off by 2-3 hours. Times are now converted to UTC.
- **Paper vs real.** A reply in PAPER mode could close or mark a DEMO trade, and a PAPER signal could be approved into a real order. Both are blocked.
- **Netting accounts.** A second signal on a symbol the app already holds is refused instead of being merged into the first trade with its SL/TP overwritten.
- **Large accounts.** Each position is capped at *max lot per position* instead of the whole signal being rejected.
- **Account switch.** Moving to a new demo account no longer trips a drawdown or daily-loss lockout based on the old account's equity.
- **Deletions.** Deleting an unrelated private message could cancel a waiting signal from a channel. Deletions without a chat id now match only private and basic-group sources.
- **PAPER mode after reconnect.** Signals were rejected with "MT5 not connected". Fixed.

### Interface

- All times are shown in your local time (the log, charts and history showed UTC).
- Sidebar with icons, sections, a review-queue badge on *Signals* and a position count on *Positions*. Ctrl+1 … Ctrl+8 switch pages.
- *Positions*: totals (lots, P&L, risk), an empty state, double-click to change SL/TP, and the selection stays on the same ticket when rows move. Before, it stayed on the same row number, so it could jump to a different position.
- The execution-mode buttons now always show the mode the app is really in.
- One number format (1,234.56) in every field, whatever your Windows region.
- Charts: distinct axis labels (no more "-0.0%" twice) and a hover read-out with the time.
- App and tray icon, themed radio buttons and check marks, better light-theme colours.
- The Connection page no longer calls MetaTrader 5 from the interface thread.
